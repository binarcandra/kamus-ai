💡 Kenapa perlu API Key?

Agar fitur kamus AI berfungsi tanpa batas antrean orang lain, setiap pengguna memakai kunci gratis dari Google AI Studio. Kuncimu hanya disimpan di browser perangkat ini dan tidak dikirim ke server mana pun.

Cara Mendapatkan API Key Gratis (30 Detik):

  1. Buka Google AI Studio lalu login dengan akun Google (Gmail).
  2. Klik tombol biru "Create API key" → pilih proyek baru, lalu klik Copy pada kode yang muncul.
  3. Tempel (Paste) kode tersebut ke kotak di bawah ini dan klik Simpan.
